# External sources of fpga-mister, cloned into _Checkouts/<name> by firmware/common/scripts/checkout.sh
# (every flow's "make setup" and the build scripts use it; firmware/common/checkouts.mk reads this
# table for the Makefiles).  One line per source:
#
#   name  url  branch  rev  options
#
#   branch   branch to clone (- = the repository's default branch); $VIVADO_VER is replaced by the
#            Vivado version (release branches of the Xilinx repositories)
#   rev      commit or tag checked out (detached) and verified; - = the tip of the branch (the
#            checkout must then be at origin/<branch>, checkout.sh --check tells how to switch)
#   options  shallow (--depth 1: release branches and tags only), submodules (--recursive), or -
#
# The MiSTer sources stay untouched: changes for Vivado/Zynq are patches in firmware/common/mister/
# (applied to a copy in the build tree), never edits in _Checkouts.
# Used by: soc-prebuilt-firmware (FLOW=boot, ZynqMP boards), vivado-library (rgb2dvi, FLOW=vivado),
# Template_MiSTer (sys/ framework), Main_MiSTer (ARM application, Zynq port), Menu_MiSTer (menu core
# menu.rbf), MSX_MiSTer (MSX2/2+), SNES_MiSTer (SNES), PSX_MiSTer (PlayStation), N64_MiSTer
# (Nintendo 64). Who wrote them: README.md, section "Credits".
# The HDMI transmitter with sound of the _hdmi designs is part of this repository
# (firmware/common/ip/hdmi-tx).
